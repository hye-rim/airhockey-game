# 에어하키 🏒

컴퓨터와 하거나 방 코드로 친구와 실시간 대결하는 에어하키. [작은 오락실](https://github.com/hye-rim/smallgame)의 게임 중 하나. `public/`(`index.html` + `logic.js` + `game.js`)과 온라인 대전용 `server.js`(`ws`)로 이루어져 있습니다.

- 세로로 긴 판(300x500). 아래 절반이 내 편, 위 절반이 상대 편. 패들(원)로 퍽을 쳐서 **상대 쪽 끝 가운데 골대**에 넣으면 1점. 먼저 **7골**이면 승리, 시간(컴퓨터 3분·온라인 5분)이 끝나면 점수가 높은 쪽 승리(같으면 무승부)
- 패들은 손가락·마우스를 따라가되 **최고 속도**가 있고 **내 쪽 절반 밖으로는 못 나간다**. 터치는 손가락에 가리지 않게 패들이 손가락 조금 위에 놓인다
- 골이 들어가면 점수를 잃은 쪽 앞에 퍽을 다시 내놓는다 (1.3초 뒤)
- 컴퓨터: 쉬움은 느리고 퍽의 지금 자리만 쫓으며 조금 비틀거리고, 어려움은 퍽이 튕겨 올 자리를 미리 가늠해 막고 틈이 나면 골대를 향해 친다 (어려움 대 쉬움 모의 대전 20판 합계 133 대 1골)
- 컴퓨터를 이긴 횟수는 `airhockeyWins` (로비 표시용), 온라인 전적은 `airhockeyOnline`
- **온라인 대전**: 빠른 대전 · 4글자 방 코드(초대 링크 `?room=코드`) · 재접속(30초) · 기권 · 한 판 더(아래·위 자리 교대). **서버가 같은 물리(`public/logic.js`)로 초당 120번 계산**하고 초당 30번 퍽·패들 위치를 보낸다. 브라우저는 사이를 같은 물리로 메워 그리고, 내 패들은 바로 따라가게(예측) 한다. 서버는 패들 목표만 받아 속도·위치를 규칙대로 제한하므로 순간이동·초과 속도는 통하지 않는다. 방 코드를 짧은 시간에 많이 틀리면 잠깐 막는다
- M 소리

규칙·물리·컴퓨터는 `public/logic.js`(화면 없이 Node 로 시험할 수 있다), 화면·입력·소리·온라인은 `public/game.js`, 방·매칭·실제 계산은 `server.js`. 시험은 `npm test`(= `node --test`): `test/logic.test.js`(벽·골·서브·패들 충돌·속도 제한·같은 입력이면 같은 결과·컴퓨터 강약), `test/server.test.js`(서버를 띄워 매칭·위치 전송·골로 끝나는 판·시간 종료·재접속 등). 서버 시험은 `MATCH_MS`·`GOAL_LIMIT` 환경변수로 시간과 목표 점수를 줄인다.
